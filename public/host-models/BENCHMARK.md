# Latency benchmark model

`benchmark-latency.glb` is the Khronos glTF Sample **Box** model (CC0 / MIT-style sample content).

It is committed to this repo **only** for testing download latency from GitHub Pages. Your proprietary GLBs in `hosting/models/` stay local and are gitignored.

Source: [KhronosGroup/glTF-Sample-Models — Box](https://github.com/KhronosGroup/glTF-Sample-Models/tree/main/2.0/Box)
